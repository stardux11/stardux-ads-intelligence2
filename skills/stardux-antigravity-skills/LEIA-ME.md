# Stardux — 3 Skills para Google Antigravity

## Instalação por projeto
Copie a pasta `.agents` para a raiz do projeto aberto no Antigravity. Os três arquivos precisam permanecer em pastas distintas, cada um com o nome `SKILL.md`.

## Instalação global no Windows
Copie as três pastas que estão em `.agents/skills/` para:
`C:\Users\SEU_USUARIO\.gemini\config\skills\`

## Como chamar
- `/stardux-web-design-pro`: estratégia, copy e arquitetura de páginas.
- `/frontend-design`: implementação frontend com estética autoral.
- `/proank-web-design`: revisão e polish de site já criado.

As skills também podem ser identificadas automaticamente pelo agente.

## Integração com Obsidian
Estas skills não conectam o Obsidian automaticamente. É necessário dar acesso ao cofre via pasta do workspace ou servidor MCP configurado à parte. Não inclua senhas, tokens ou dados privados no repositório.

## Nota sobre fontes
A skill `frontend-design` nesta coleção é autoral, inspirada na categoria de uso divulgada pela Anthropic, não o arquivo oficial. Para obter a versão original, consulte https://github.com/anthropics/skills/tree/main/skills/frontend-design.

A terceira skill traz “Proank” no nome solicitado, mas a fonte não pôde ser confirmada. É um esqueleto útil de QA visual e pode ser atualizado quando houver um link de referência.

Documentação oficial de instalação: https://www.antigravity.google/docs/skills
